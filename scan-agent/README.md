# Elegance Scan Agent (سكان 1 / 2 / 3)

برنامج صغير على ويندوز بجانب السكانر USB. يشتغل في الخلفية ويبعت الباركود للسيرفر من غير ما تفتح المتصفح.

| الملف | المحطة | النتيجة |
|------|--------|---------|
| `start-scanner1.cmd` | سكان 1 | منتهية |
| `start-scanner2.cmd` | سكان 2 | ديزاين |
| `start-scanner3.cmd` | سكان 3 | فينيش |

## التثبيت على كل جهاز

1. انسخ مجلد `scan-agent` للجهاز (ديزاين / فينيش / ريسبشن).
2. تأكد إن Node.js متثبت.
3. اعمل حساب موظف من الأدمن:
   - جهاز الديزاين → حساب **سكان 2**
   - جهاز الفينيش → حساب **سكان 3**
   - جهاز الريسبشن → حساب **سكان 1**
4. شغّل الملف المناسب مرة واحدة (مثلاً `start-scanner2.cmd`).
5. هيتفتح ملف الكونفيج — حط **الإيميل** و**الباسورد** واحفظ.
6. شغّل نفس الملف تاني — لازم تشوف `Ready — waiting for barcode scans`.

## ملاحظات

- السكانر لازم يكون وضع **Keyboard wedge** (زي الكيبورد).
- بعد التشغيل هتتفتح صفحة Capture محلية — **امسح وأنت عليها**.
- سيّب صفحة Capture والنافذة السودا شغّالين؛ متقفلهمش.
- الأفضل لغة الكيبورد **English** وقت المسح.

## تشغيل يدوي

```bat
cd scan-agent
npm install
node agent.js config.scanner2.json
```
