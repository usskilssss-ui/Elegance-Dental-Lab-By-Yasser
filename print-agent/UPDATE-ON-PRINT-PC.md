# تحديث Print Agent (لابتوب الطباعة)

الشيت المطبوع بقى **أبيض/أسود**:
- كل سن عليه رقم + كود الخامة (`Zr` زيركون، `Em` إيماكس، …)
- تهشير مختلف لكل خامة
- الجسر ظاهر بـ `══` بين الأسنان + صندوق ملخص تحت الشارت: `جسر Em: 14—15—16`

## على لابتوب الطباعة
1. انسخ الملف الجديد `print-agent/agent.js` مكان القديم
2. أوقف الـ agent
3. شغّله تاني:
   ```bat
   cd print-agent
   node agent.js
   ```
4. اطبع ريكويست **جديد** فيه أسنان
