# تحديث Print Agent (لابتوب الطباعة)

الكود بتاع الشيت الملوّن موجود في مجلد `print-agent` — **مش بيتنشر مع Vercel**. لازم يتحدّث يدوي على جهاز الطباعة.

## الطريقة الأسهل

1. على لابتوب الطباعة، افتح مجلد المشروع (أو انسخ مجلد `print-agent` الجديد من جهاز التطوير).
2. مهم: الملف `print-agent/agent.js` لازم يكون فيه `c.teeth` و `مخطط الأسنان` بألوان FDI.
3. أوقف الـ agent القديم (Ctrl+C في التيرمنال، أو وقف الخدمة).
4. من داخل `print-agent`:
   ```bat
   npm install
   node agent.js
   ```
   أو شغّل الـ `.bat` / الخدمة المعتادة عندكم.
5. اطبع ريكويست جديد فيه أسنان محددة — الشيت لازم يتلوّن.

## ملاحظة

- الفرونت (Vercel) + الباكند (Railway) لازم يكونوا محدّثين برضو عشان `teeth` توصل في أمر الطباعة.
- لو الـ agent قديم، الشيت هيفضل فاضي حتى لو الفرونت شغال.
